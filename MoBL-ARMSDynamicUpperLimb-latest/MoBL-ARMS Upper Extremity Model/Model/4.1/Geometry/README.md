# MoBL-ARMS display geometry

This directory contains only the 33 `.vtp` meshes referenced by
`DefaultMOBL_ARMS_fixed_41.osim`. They were sourced from the public
[CEINMS-RT UpperLimbModel](https://github.com/CEINMS-RT/UpperLimbModel)
repository so the optional OpenSim motion viewer can render the model.

See `LICENSE_MoBL_ARMS.txt` in this directory for the model's license and
non-commercial-use terms.
